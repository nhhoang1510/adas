# ADAS Perception Models

Pre-trained deep learning models for Advanced Driver Assistance Systems (ADAS).

## 📦 Model Weights
- **model/yolopv2.pt** (~149 MB): YOLOPv2 Panoptic Driving Perception (Vehicle Detection, Drivable Area, Lane Detection)
- **model/tsr.pt** (~54 MB): Traffic Sign Recognition (32 classes of Vietnamese road signs, YOLO11)
